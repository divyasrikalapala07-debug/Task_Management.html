# Task Management Application

A responsive web application for creating, updating,
deleting and tracking tasks.

## Features

- User authentication
- Create tasks
- Update tasks
- Delete tasks
- Complete tasks
- Task status tracking
- Due date
- LocalStorage
- Responsive design
- Mobile friendly interface
